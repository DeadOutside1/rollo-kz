# ROLLO.KZ — Официальный сайт жалюзи и рулонных штор на заказ

Современный, премиальный, высококонверсионный и молниеносный сайт для казахстанской компании **ROLLO.KZ**, разработанный для полной замены Tilda (экономия от 4 500 ₸ в месяц) и бесплатного хостинга на Vercel.

## 🛠 Технологический стек

* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS.
* **Иконки:** Lucide React (профессиональные векторные иконки).
* **Serverless Backend:** Vercel Serverless Function (`/api/telegram.ts`) для безопасной отправки лидов в Telegram без раскрытия токенов ботов.
* **Тестирование:** Vitest (автоматические тесты формулы калькулятора).
* **Стили и UX:** Палитра Deep Emerald (`#174D3A`, `#267653`, `#22c55e`), адаптивная сетка (320px–1440px), плавающий виджет связи, оптимизированные WebP-изображения.

## 🤖 Инструкция: Подключение Telegram-бота

Чтобы заявки с сайта мгновенно падали вам или вашим менеджерам в Telegram:

### Шаг 1. Создайте Telegram-бота
1. В Telegram откройте поиск и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Задайте имя боту (например: `Rollo.kz Заявки`) и юзернейм (например: `rollo_kz_lead_bot`).
4. `@BotFather` выдаст **HTTP API Token** вида: `7123456789:AAFn_XXXXXXX_XXXXXXXXXXXXXXX`.
5. Скопируйте этот токен — это ваш `TELEGRAM_BOT_TOKEN`.

### Шаг 2. Узнайте ваш Chat ID
* **Если заявки нужны вам в личные сообщения:**
  1. Напишите боту **[@userinfobot](https://t.me/userinfobot)**.
  2. Он ответит сообщением с вашим `Id` (например: `123456789`).
  3. Обязательно **нажмите /start в вашем новом боте**, чтобы разрешить ему писать вам!
* **Если заявки нужны в группу с менеджерами:**
  1. Добавьте созданного бота в группу менеджеров.
  2. Назначьте бота администратором группы.
  3. Отправьте любое сообщение в группу, затем откройте в браузере:  
     `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
  4. Найдите параметр `"chat":{"id": -100XXXXXXXXXX}` — это ваш `TELEGRAM_CHAT_ID`.

## ☁️ Инструкция: Бесплатный деплой на Vercel

1. Загрузите проект в ваш репозиторий на **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: ROLLO.KZ modern website"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/rollo-kz.git
   git push -u origin main
   ```
2. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub (аккаунт бесплатный).
3. Нажмите **«Add New...» -> «Project»** и выберите ваш репозиторий `rollo-kz`.
4. В разделе **Environment Variables** добавьте:
   * `TELEGRAM_BOT_TOKEN` = `ваш_токен_от_BotFather`
   * `TELEGRAM_CHAT_ID` = `ваш_chat_id`
   *(Если Google Ads пока не настроен, эти поля можно оставить пустыми)*.
5. Нажмите **Deploy**. Через 30 секунд сайт будет доступен в интернете!

## 🌐 Инструкция: Подключение собственного домена rollo.kz

У вас уже куплен домен `rollo.kz`. Чтобы привязать его к Vercel:

1. В Vercel откройте ваш проект, перейдите во вкладку **Settings -> Domains**.
2. В поле ввода введите: `rollo.kz` и нажмите **Add**.
3. Vercel предложит добавить также `www.rollo.kz` с редиректом на `rollo.kz` — подтвердите это (рекомендуется).
4. Vercel покажет DNS-записи, которые нужно внести у вашего регистратора домена (например, Hoster.kz, PS.kz и др.):
   * **Основной домен (`rollo.kz`):**
     * **Тип:** `A`
     * **Имя/Хост:** `@` (или пустое/rollo.kz)
     * **Значение:** `76.76.21.21`
   * **Поддомен `www` (`www.rollo.kz`):**
     * **Тип:** `CNAME`
     * **Имя/Хост:** `www`
     * **Значение:** `cname.vercel-dns.com`
5. Сохраните изменения в панели регистратора.
6. В течение 10–30 минут DNS обновится, Vercel автоматически выпустит бесплатный **SSL/HTTPS сертификат**, и сайт станет доступен по адресу `https://rollo.kz`.

## 📊 Инструкция: Настройка Google Ads и Аналитики

Сайт полностью подготовлен для рекламных кампаний Google Ads с отслеживанием ключевых конверсий:

### События, отслеживаемые на сайте:
1. **Главная конверсия:** Успешная отправка заявки (срабатывает **только** после подтверждения от сервера, персональные данные НЕ передаются, исключен дублированный учет повторными кликами).
2. **Клик по номеру телефона** (`tel:`).
3. **Клик по кнопке WhatsApp** (`wa.me`).
4. **Расчет в калькуляторе** (воронка заинтересованности).

### Как настроить:
1. В аккаунте Google Ads перейдите в **Инструменты и настройки -> Конверсии -> Новое действие-конверсия**.
2. Выберите «Веб-сайт», укажите URL `https://rollo.kz`.
3. Создайте конверсию вручную:
   * Категория: *Отправка формы для потенциальных клиентов* (Lead)
   * Имя: *Заявка с сайта Rollo.kz*
4. На этапе установки тега Google Ads выдаст:
   * **Google Tag ID** (например, `AW-1234567890`)
   * **Ярлык конверсии (Conversion Label)** (например, `AbC_xYz123456`)
5. Вставьте эти значения в файл `.env` локально или в **Environment Variables** в Vercel:
   ```env
   VITE_GOOGLE_ADS_ID=AW-1234567890
   VITE_GOOGLE_ADS_LEAD_LABEL=AbC_xYz123456
   VITE_GOOGLE_ADS_CALL_LABEL=
   VITE_GOOGLE_ADS_WHATSAPP_LABEL=
   VITE_GA4_MEASUREMENT_ID=G-XXXXXXXXXX
   ```
6. Нажмите **Redeploy** в Vercel. Конверсии начнут учитываться автоматически!

## ⚙️ Как легко редактировать цены, контакты и товары

Все данные сайта редактируются в одном файле:  
👉 **`src/config/site.ts`**

* **Поменять номер телефона:** измените поля `phone` и `phoneRaw`.
* **Поменять цены за кв.м:** в массиве `BLIND_TYPES` измените `pricePerSquareMeter` у нужного типа.
* **Поменять адрес или график работы:** измените поля `address` и `workingHours`.
* **Добавить новые фото:** положите файлы в `public/images/` и укажите путь в `site.ts`.
